# Alumel Sistema

App de Alumel Estructuras para cotizar ventanas serie 744 y 8025, puertas, divisiones y vidrio templado; sacar cortes; llevar obras, clientes y cuentas de cobro.

- Dirección: https://richard-1504.github.io/alumel-app/
- Funciona sin internet una vez instalada (iPhone: Safari → Compartir → Agregar a inicio).
- Sincronización entre equipos con Firebase: ver `LEEME.txt`.
